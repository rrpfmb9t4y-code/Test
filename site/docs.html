What you can do with Bursor

Bursor brings agents into every part of your workflow. Hand off a task and let an agent plan, edit, and test across your codebase — or stay in the loop with inline edits and Tab completions.

  • Agents — delegate multi-step tasks that run end to end.
  • Tab — magically accurate autocomplete that predicts your next edit.
  • Cloud Agents — run agents on their own machines, in parallel.
  • Code Review — let Bursor review PRs and catch bugs before you merge.
  • CLI — drive Bursor from your terminal and CI.

Models

Bursor supports every frontier model. Switch between Builder 2.5, Opus 4.8, GPT-5.5, Gemia 3.1 Pro, and Grok 4.3, or let Bursor pick the best model for each task automatically.
